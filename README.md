# 🚚 Fleet Tracker API

A mock REST API for tracking delivery vehicles in real time, built for logistics simulation projects.

## 📦 Features
- Register vehicles and locations
- Real-time location updates
- REST endpoints (GET, POST, PUT)

## 🛠 Tech Used
`Python` `Flask` `Postman`

## 🚀 How to Run
1. Clone this repo
2. Run `python app.py`
3. Use Postman to test `/vehicles` endpoints
